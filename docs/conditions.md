# 計算条件定義書 — 人頭モデル 風圧場

## 目的

人頭（Super Average Head）に対する定常風の圧力場を取得し、**圧力で色付けされたベクトル（速度または圧力勾配）** を ParaView で可視化する。

周波数解析は将来フェーズ。今回は **10 s の非定常計算** で表面圧力の時系列を保存し、平均圧力場を主に評価する。

## 幾何

| 項目 | 値 |
|------|-----|
| モデル | Super Average Head（STL 推奨） |
| ファイル | `models/Super_Average_Head.stl` |
| 三角形数 | 24,820 |
| バウンディングボックス | 約 0.26 × 0.24 × 0.36 m |
| 単位 | メートル（m） |

> **注意:** OBJ と STL で座標軸の向きが異なる。OpenFOAM では **STL のみ** を使用する。

## パラメータスイープ（44 通り）

| 軸 | 値 | 数 |
|----|-----|-----|
| 顔の向き（ヨー角 ψ） | 0°, 90°, 180°, 270° | 4 |
| 風速 U∞ | 0.0, 0.5, 1.0, …, 5.0 m/s（0.5 m/s 刻み） | 11 |
| **合計** | | **44** |

### 座標系の约定

```
        +Z (上)
         |
         |   +X (風の吹く方向、固定)
         |  /
         | /
         +------ +Y
```

- **風向き:** 常に **+X 方向**（入口境界）
- **顔の向き:** 頭部を **Z 軸周りに ψ 回転**（0° = 顔が +X を向く）
- 対称平均頭モデルだが、ヨー角により鼻・頬・後頭の向きが変わるため **対称境界条件は使わない**

### 風速 0 m/s

数値的に不安定になりやすい。**推奨:** ケースは生成するが、本番スイープではスキップするか、別途 `simpleFoam` 定常（U=0）で扱う。

## 推奨ソルバー・物理モデル

| 項目 | 推奨 | 理由 |
|------|------|------|
| ソルバー | **`pimpleFoam`** | 10 s 非定常・将来の FFT に対応 |
| 乱流 | **`kOmegaSST`（RAS）** | 外部流れの定番。ノート PC で LES は非現実的 |
| 圧縮性 | **非圧縮** | U∞ ≤ 5 m/s、Ma ≪ 0.1 |
| 流体 | 空気 20°C | ν = 1.5×10⁻⁵ m²/s, ρ = 1.2 kg/m³ |

### なぜ LES / DDES にしないか

| 方式 | ノート PC（32 GB）での 44 ケース |
|------|----------------------------------|
| LES / DDES | 1 ケースあたり数時間〜数日 → **現実的でない** |
| URANS (`pimpleFoam` + SST) | 1 ケース 30分〜2時間程度 → **バランス良** |
| 定常 `simpleFoam` | 数分〜十数分 → **スクリーニング用** |

**2 段階運用を推奨:**

1. **Phase A:** `simpleFoam` で 44 通りの **平均圧力場** を高速取得
2. **Phase B:** 代表ケース（例: ψ=0°, U=1,3,5 m/s）で `pimpleFoam` 10 s

## 計算域・メッシュ

| 項目 | 推奨値 |
|------|--------|
| 計算域 | 約 3.0 × 1.5 × 2.0 m（頭を中心） |
| 入口 | x = −1.0 m |
| 出口 | x = +2.0 m |
| 背景セル | 40 mm（粗い） |
| 頭表面近傍 | 5〜10 mm（snappyHexMesh 3 レベル） |
| 目標セル数 | **80万〜150万**（32 GB RAM 向け） |
| y+（壁関数） | 30〜100 |

## 時間積分

| 項目 | 値 |
|------|-----|
| 物理時間 | 10 s |
| 初期過渡 | 最初 2 s は捨てる（統計安定化） |
| Δt | CFL ≤ 0.5 で自動調整、初期値 5×10⁻⁴ s 程度 |
| 書き出し間隔 | 0.01 s（10 s → 1000 スナップショット/ケース） |

## 境界条件

| 境界 | 条件 |
|------|------|
| inlet | `fixedValue` U = (U∞, 0, 0) |
| outlet | `zeroGradient` U, `fixedValue` p = 0 |
| sides + top | `slip` または `symmetry`（遠方場近似） |
| ground | `noSlip`（任意: 頭のみ浮かせるなら slip でも可） |
| head 表面 | `noSlip` |

## 出力・可視化（ParaView）

欲しい表示: **圧力で色付けされた矢印**

| レイヤー | ParaView 操作 |
|----------|---------------|
| 圧力の色 | 頭表面 `p` または `pMean` をカラーマップ表示 |
| 矢印 | `Glyph` フィルタで **速度ベクトル U** を表面法線方向 or 3D 表示、**Coloring = p** |
| 代替 | `Calculator` で `mag(grad(p))` を矢印の色に使用 |

推奨出力:

- `postProcessing/surfaces/head/p` — 表面圧力時系列
- `postProcessing/fieldAverage` — 時間平均 p, U

## ハードウェア前提と現実的な見積もり

| 項目 | スペック |
|------|----------|
| CPU | Ryzen 9 8940HX（16C/32T） |
| RAM | 32 GB |
| GPU | RTX 5070 Laptop |

> **事実:** 標準 OpenFOAM は **GPU 非対応**。RTX 5070 は本計算では使えない。

| フェーズ | 1 ケース | 44 ケース（直列） |
|----------|----------|-------------------|
| simpleFoam（定常） | 5〜15 分 | 約 4〜11 時間 |
| pimpleFoam（10 s） | 30 分〜2 時間 | 約 22〜88 時間 |

**推奨:** `simpleFoam` で全 44 → 問題なければ `pimpleFoam` を必要ケースのみ。

## ケース命名規則

```
cases/run/psi{000|090|180|270}_U{000|005|010|...|050}/
```

例: `psi090_U030` = ヨー 90°, 風速 3.0 m/s
